# Crashout Poker SFX source

The production OGG poker-table SFX in this folder are sourced from **Kenney Casino Audio**, a CC0 / public-domain sound-effects pack by Kenney.

Primary source:
https://opengameart.org/content/54-casino-sound-effects-cards-dice-chips

License:
Creative Commons CC0 1.0 Universal / public domain.

Attribution is not required. Credit to Kenney is appreciated but optional.

The Crashout production filenames intentionally remain stable so the poker engine can swap sound libraries without changing gameplay code.

This replacement pass uses physical card and poker-chip recordings only:
- card slides, fans, places, shoves and shuffle
- chip lays, collisions, stacks and handling

The previous procedurally synthesized OGG layer was replaced.
